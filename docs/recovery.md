# Recovery and return to Stock

Gate 1 / Point of Return is satisfied by the current evidence review. The
official Creality/Cloner recovery route is preserved and offline-material
validated, but its complete destructive execution was not performed on the
reference device and is not guaranteed.

The current recovery state, evidence levels, preserved artifacts, and limits
are recorded in [`docs/recovery-current-state.md`](recovery-current-state.md).
The current storage and A/B layout is in
[`docs/storage-layout.md`](storage-layout.md), and the applicable licensing
and redistribution rules are in
[`docs/licensing-and-provenance.md`](licensing-and-provenance.md).

The current return boundary must remain explicit:

- software-only Fre3nder -> Stock: **REQUIRES QUALIFICATION**;
- manual power-cycle Stock recovery: **QUALIFIED ON DEVICE (2/2)**;
- retained Stock F005 MCU image and the documented bootloader path are
  preserved, but this does not establish a complete host round trip;
- no recovery, deployment, or firmware tool grants implicit authorization for
  physical use.
